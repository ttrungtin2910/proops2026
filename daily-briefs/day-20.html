Mid-Point Review — Artifact Quality Gate
You completed Days 1–19. You have 16 memory files, working manifests, deploy scripts, and a Terraform module. Has the knowledge actually moved into your head — or only into your files? Today proves which one.
Day 20 is the gate between Weeks 1–4 (foundations) and Weeks 5–8 (CI/CD, observability, graduation). Knowledge gaps after this point compound — every CI/CD pipeline you build assumes Docker, K8s, Helm. Every observability dashboard assumes you can read Pod logs. The K8s knowledge map showed that some trainees finished Days 12–15 without understanding what a Deployment is. This day catches that — for K8s and for everything else. The output of today is not "I passed"; it is an honest map of what you know vs what you have a file for. Surfacing a real gap today is worth more than hiding one.
Day 20 ground rules — read before starting
Today is a self-audit + mentor verification, not a learning day. The point is to find your real gaps, not to perform competence. We have already calibrated the rubric against the assignments — generic agent output, copy-paste content, and "I checked the box" answers are easy to spot. Surface a gap honestly today and you get full credit for the row. Hide a gap and get caught in Phase 3 (live drill with mentor) and you lose the row plus a flag.
R1
No Claude during Phase 2 (closed-book quiz) and Phase 3 (live drill). Open a fresh document. No memory files open. No tabs to your repo. Phone face down. kubectl and shell are allowed in Phase 3 only.
R2
Memory files must reference YOUR specific project. Real service names, real error messages you encountered, commit hashes from your repo. Generic content fails the rubric. We will diff against your git log.
R3
Phase 3 is live with the mentor on screenshare. Failure scenario assigned at session start — you do not know which one in advance. 15 minutes to diagnose using only kubectl/docker/aws CLI. No Claude, no Google, no notes.
R4
Random spot-check in 1-on-1. Mentor will pick 5 questions from the 30-question quiz at random and ask you to re-answer in conversation. If your written answers do not match your spoken ones, the row is voided.
R5
Honest gap = full credit. The rubric explicitly rewards "I cannot answer this; my memory file is generic." A surfaced gap with a Week-5 remediation plan = full row. A hidden gap = -2 plus a flag.

Phase 3 — Live failure drill (with mentor)
3
Mentor presents a broken environment. You diagnose live on screenshare. 15 minutes.
30 min slot
Live
This is the cheat-killer. You cannot ask Claude. You cannot read your memory file mid-session. You either have the muscle memory or you don't — and that is exactly what we need to know to plan Week 5 for you.
1
Book a 30-minute slot with the mentor in the cohort calendar. Bring your own cluster (minikube + your project deployed) or use the shared scenario environment if your cluster is gone.
2
At session start, mentor draws ONE scenario from the basket: broken Pod (CrashLoopBackOff / 0/1 READY / Pending), broken Service (selector mismatch / endpoints empty), broken Ingress (404 / 502 / wrong path), broken Helm release (PVC pending / wrong override / failed upgrade), broken Terraform state (drift / orphan / missing variable).
3
You get 15 minutes to diagnose. Allowed: kubectl/helm/docker/aws/terraform CLI, your terminal history. Not allowed: Claude, Google, your memory files, your daily logs. Verbalize what you are looking for at each step ("now I'm checking events because describe didn't show probe failures").
4
At end of 15 min, mentor asks: (a) what is the root cause, (b) what is the fix, (c) which memory file should already cover this. If your memory file does cover it but you didn't reach for it — that's a "knowledge in file but not in head" gap.
5
Mentor scores: 3/3 = found root cause + fix in time. 2/3 = found root cause but not the fix. 1/3 = made progress but did not isolate. 0/3 = lost. +1 bonus if you correctly named which memory file covers this.
Deliverable: memory/day-20-drill.md — write up the scenario you got, your diagnostic path (every command you ran), what you found, what you missed, and the fix. Mentor co-signs the score.
Why this is hard to fake: the scenario is randomly assigned at session start. The 15-minute clock + screenshare + no-Claude rule means trainees who copy-pasted memory files are visibly stuck. Trainees who ran the deliberate failure drills on Days 12–19 walk through this in 5 minutes.
